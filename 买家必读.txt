【闲鱼爆款文案生成器 · 使用说明】

一、运行环境
Windows 10/11 电脑，已安装 Python 3.10 或更高版本。

二、三步开始
1. 解压压缩包到任意文件夹
2. 双击 start.bat
3. 填写商品信息 → 点「生成文案」→ 点「复制全部」→ 粘贴到闲鱼

三、想要更好的文案
点右下角「设置 API」，填入 DeepSeek API Key（platform.deepseek.com 可免费注册）。
不填也能用，走内置模板。

四、常见问题
- 闪退：确认 Python 已装且勾选了 Add to PATH
- 报 401：API Key 不对，重新生成
- 杀毒软件拦截：加入信任即可，软件无联网上传，只调用你配置的 API

五、声明
本工具仅辅助文案创作，请按商品真实情况修改后发布。
